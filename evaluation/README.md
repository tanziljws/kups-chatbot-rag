# Evaluasi chatbot

`questions.jsonl` adalah seed set kecil untuk memeriksa sumber, jawaban dasar, ambiguitas, dan pertanyaan yang harus ditahan. Ini belum cukup untuk menyatakan target penerimaan 85%.

Sebelum pilot, tambah menjadi 50–100 pertanyaan yang ditinjau orang yang memahami Perhutanan Sosial. Setiap baris harus mencantumkan jawaban acuan, sumber resmi, dan apakah chatbot seharusnya meminta klarifikasi. Sertakan typo, singkatan, data dinamis, pertanyaan di luar cakupan, serta sumber yang berbeda versi. Tinjau jawaban secara manual; kemiripan kata bukan bukti bahwa jawaban benar.
